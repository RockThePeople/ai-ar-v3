## 0. 운영 원칙 (매 세션 적용)

```
1. 계획 → 승인 → 구현 → 검증.  코드부터 쓰지 않는다.
2. 한 세션 = 한 게이트.  게이트가 닫히면 /clear 하고 새 세션.
3. 실패한 접근을 계속 고치지 않는다.  §5 의 재시도 상한을 넘으면 되돌리고 폴백으로 간다.
4. "필수적으로 구현하되 최소한으로 구현한다."  스코프 확장은 이 파일을 고친 뒤에만.
5. 결정은 대화가 아니라 파일에 남긴다.  이 파일 또는 docs/adr/ 에.
6. 비밀은 코드·문서·커밋에 절대 넣지 않는다 (§7).
7. **테스트 통과는 동작의 증거가 아니다.**  "그 코드가 떴는가" 와 "그게 실제로
   무엇을 바꿨는가" 는 별개의 사실이다.  육안 산출물이 없으면 미검증으로 적는다.
8. **프롬프트를 작성할 때 세 세션 간 의존성을 고려해 스케줄링한다.**
   보고가 없는 프롬프트는 **아직 실행 중**으로 간주하고, 그것에 의존하는 작업을
   내보내지 않는다.  의존이 없는 작업만 병렬로 내보낸다.
```

기록     내보낸 프롬프트와 도착한 보고를 §6 에 웨이브 단위로 적는다
금지     "아마 끝났을 것" 으로 다음 작업을 내보내는 것.  보고가 곧 완료 신호다

## 1. 대목표 (한 문장)

> **자연어로 만든 3D 오브젝트의 일부를 화면에서 골라 자연어로 바꾸면,
> 바뀐 부분만 실제로 바뀌고 바뀐 바이트만 오간다.**

```
(A) 효능   마스크 안이 지시대로 실제로 변한다        🔴 한 번도 성립한 적 없다
(B) 보존   마스크 밖은 바이트 단위로 불변이다         △ 계측됨 — 단, (A)가 no-op 인 상태에서
(C) 절감   변경 청크만 전송되고 그 자리만 교체된다     △ 계측됨 — 단, (A)가 no-op 인 상태에서
```

🔴 **rev3 의 핵심 인식.** 지난 프로젝트에서 (B)(C)가 "통과"한 것은 **(A)가 아무것도
바꾸지 않은 상태에서 잰 값**이다. 아무것도 안 하는 구현이 보존·절감 검사를 전부
통과하는 것은 당연하다. **따라서 (B)(C)도 재검증 대상이다** — 눈에 보이게 바뀐
콘텐츠 위에서 다시 재기 전까지는 증명이 아니다.

### D1. 백본을 TRELLIS 1 으로 통일한다 — 생성·편집 동일 백본
```
결정   생성도 편집도 VoxHammer 가 벤더링한 TRELLIS 1 (image-large) 하나만 쓴다.
       TRELLIS.2-4B 는 이번 범위에서 내린다.
이유   ① VoxHammer 가 TRELLIS 1 백본이라 이종 구성은 자산 변환 계층이라는 순수 부채
       ② 편집은 자기가 만든 자산을 inversion 해야 정확하다 — 이종이면 이 전제가 깨진다
       ③ VRAM 여유: 편집 피크 14,180 MiB / 24 GB.  TRELLIS.2 상주 6 GB 회수까지
       ④ 이번 목표는 사실성이 아니라 국소성이다
대가   생성 품질·해상도 하락.  S6 사용자 판정에서 허용 여부를 본다
되돌리는 조건   S6 에서 "데모로 못 쓸 품질" 판정 시에만.  그전엔 재론 금지
```

```

       ④ cbin-delta 의 실동작을 여기서 처음 증명한다 (D2)
       ⑤ best-practices §6: "가짜 구현으로 전 구간을 먼저 관통시킨다.

  2. 머리 마스크를 서버측에서 산출 (find_head_bbox 이식).  halo 팽창은 **클램프 뒤에**
  3. assemble.py — 마스크 자리를 비우고 donor 를 크롭·정수 평행이동으로 삽입
     ⚠️ 스케일 인자 없음. 크기는 donor_crop_fraction 으로만
  4. 부기 = 배치에서 유도.  전칭 규칙 ∀c ∈ 부기 : c ∈ changed ∨ c ∈ removed
  5. 마스크 밖은 **부모 바이트 승계**.  재디코딩본을 쓰지 않는다
  6. DebugView 를 :8083 에 — 원본 / 결과 / 마스크 / 변경청크 하이라이트 4분할
  7. 점유 교집합이 몇 셀을 지웠는지 로그 (그 단계가 밥값 하는지 자증)

게이트 G2   ★ 효능   DebugView 에서 **호박 머리가 육안으로 보인다** (사용자 확인)
                     AND 마스크 안 실루엣 대칭차 > 15%
            ★ 보존   마스크 밖 바이트 동일률 100%
                     AND 마스크 밖 기하 거리 = 대조군 잡음 수준 (해시 비교 아님)
            ★ 절감   전송 절감 > 40%
   ⇒ 이 셋이 동시에 나오면 (A)(B)(C)가 **처음으로 함께** 성립한다
비용 상한   2세션
```
