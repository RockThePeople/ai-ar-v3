# ADR — 결정 기록

결정은 대화가 아니라 파일에 남긴다 (`docs/PROGRESS.md` §0.5).

- **확정 결정**은 `docs/PROGRESS.md` §2 에 적는다 (D1~D4).
- 그보다 국소적이거나, 되돌린 결정의 **이유**를 남겨야 하는 것은 여기 적는다.
- 특히 **골든 벡터를 재생성해야 하는 계약 변경**은 반드시 여기 ADR 을 먼저 남긴다
  (`CLAUDE.md` 계약 변경 규칙 2).

## 파일 이름

```
NNNN-소문자-하이픈-제목.md      예: 0001-cbin-delta-as-is-import.md
```

## 틀

```markdown
# NNNN. 제목

- 상태: 제안 | 채택 | 폐기 | 대체됨(→ NNNN)
- 날짜: YYYY-MM-DD
- 관련: PROGRESS §N / 게이트 GN

## 맥락
무엇이 문제였나. 어떤 사실이 관측됐나.

## 결정
무엇으로 정했나.

## 대가
무엇을 포기했나.

## 되돌리는 조건
어떤 관측이 나오면 이 결정을 재론하나.
```
