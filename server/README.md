# server/ — 아직 비어 있다

이 디렉터리는 **의도적으로 스켈레톤이다.** 구현은 다음 세션이다.

`docs/PROGRESS.md` §5 의 세션 경계에 따라, S1(부트스트랩)에서는 리포 구조와 계약
편입만 한다. 서버 로직 · DebugView · 복셀화는 **S2(관통)** 에서 쓴다.

| 것 | 담당 | 근거 |

| 오케스트레이터 (잡 인메모리) | 3090 | PROGRESS §5 S2 |

## 여기 코드를 쓸 때의 규칙

- `contract/` 의 `deltacontract` 를 **임포트해서** 쓴다. 복사·재구현하지 않는다.
- 호스트·포트·경로는 전부 환경변수. `CLAUDE.md` 의 보안 규칙을 따른다.
- 새 의존성을 추가하기 전에 사용자에게 확인받는다.
