# 측정으로 닫힌 것들

이 구현이 지금 모양인 이유. **전부 실측이고, 추측은 없다.**

---

## 1. 재디코딩은 재현되지 않는다 → 승계가 필요하다

```
기증자 없이 base 만 다시 디코딩한 대조군
  청크 해시 일치      0 / 152
  기하 변화 중앙값     0.0002 셀      ← 부동소수 잡음
```

바이트는 전부 다른데 기하는 사실상 같다.
⇒ **검증은 해시가 아니라 대조군 대비 기하 거리로.**
⇒ 안 바뀐 청크는 재디코딩본이 아니라 **부모 바이트를 승계**해야 한다.

## 2. 좌표 스케일은 인접성을 파괴한다

```
6-이웃 쌍 유지율   s=1.0  100%
                  s=1.5   50%
                  s=2.0    0%
```

희소 격자에서 좌표를 늘리면 이웃 관계가 끊어지고, 디코더가 고립 복셀마다
조각난 표면을 만든다. **크기는 크롭으로 고른다.**

## 3. 배치는 정수 평행이동만 안전하다

```
눈사람 머리 4,110복셀
  +0.5 이동 →   914복셀   (78% 소실 — rint half-to-even)
  +3.0 이동 → 4,110복셀   (무손실)
```

## 4. 부기를 diff 로 유도하면 비워진 청크가 사라진다

비워진 청크는 새 바이트가 없어서 "변경된 청크" 목록에 안 나타난다.
실측에서 8개 청크가 통째로 빠졌고, 그 자리에 옛 기하가 남았다.
⇒ **부기는 배치에서 유도한다.**

## 5. 마스크 팽창이 격자 범위를 벗어난다

`Dilate` 가 클램프보다 먼저 돌면 경계 셀에서 범위 밖 좌표가 나온다.

```
합성 마스크(스크립트·curl)  전부 [0,R-1] 안 → 버그가 안 드러난다
실제 제스처(라쏘+팽창)      경계 좌표를 포함 → 서버 쓰기 경로가 터졌다
```

⚠️ **합성 입력으로는 안 나오고 실제 제스처로만 나오는 종류의 버그다.**

## 6. 껍질 표현에서는 "부피"와 "표면"이 거의 같다

희소 latent 는 껍질만 갖는다(두께 실측 중앙값 3복셀).
"빈 내부"에는 데이터가 아예 없으므로, 부피 채움이 넣은 셀을 점유 교집합이
도로 지운다. **버그가 아니다** — 채움이 실제로 일하는 곳은 오목한 껍질뿐이다.

⇒ 교집합이 몇 개를 지웠는지 로그로 찍으면 그 단계가 밥값을 하는지 스스로 증명한다.

## 7. 델타는 전송 절감이지 저장 절감이 아니다

```
자산 하나 v1~v4   디스크 66.2 MiB
그중 중복          29.6 MiB (45%)
```

승계 청크가 버전마다 복제된다. 하드링크로 줄일 수 있지만
"아무도 제자리 수정을 안 한다"는 가정 위에 서므로, 넣는다면 승계 파일을
읽기 전용(0444)으로 만들어 그 가정을 **구조가 강제**하게 해야 한다.

## 이 프로젝트가 반복해서 물린 것 — 방법론

```
대리 지표를 의심해라 (여섯 번 물렸다)
  지표가 조용히 무의미해지는데 값은 계속 나오고, 대개 좋아 보인다
  전제가 깨졌으면 값을 내지 말고 전제가 깨졌다고 말해라
  **너무 깨끗한 숫자를 의심해라** — 잡음 바닥과 소수점까지 같으면 항진명제다

"예외가 안 났다" ≠ "안전하다"
  그 경로가 **안 돌았다**일 수 있다. 안 돌았으면 돌게 만들어라

봉쇄와 효능을 둘 다 재라
  보존 속성만 계측하면 **아무것도 안 하는 구현이 모든 검사를 통과한다**

규칙만 적고 함수를 안 주면 그 규칙은 안 지켜진다
  세 번 겪었다. 그래서 배치·부기 규칙을 assemble.py 에 코드로 넣었다

자기 실수를 잡는 검사가 자기 환경에서 안 돌면 그 검사는 자기를 보호하지 않는다
  → mirror_check.py 가 pydantic 없이도 도는 이유
```
