# W27 — 아이언맨 조건 이미지 · 형태 편집 end-to-end 성립

## ★ 조건 이미지 — `ironman-rider.png`

| 항목 | 값 |
|---|---|
| 크기 | **1024 × 1024** |
| 내용 | **바꾼 뒤의 모습 전체** — 아이언맨 머리를 쓴 라이더가 탄 오토바이 전신 |
| 배경 | 단순·균일 (흰색) |
| 알파 | 없음 (편집 경로가 rembg 를 무조건 실행해 덮는다 — D43) |
| sha256 | `0ee13d026445379cfca93b0d…` |

머리만 크롭하지 않았다 — 조건은 **전신 실루엣**으로 읽힌다. 구도는 `moto-b` 원본과
같은 꼬리말(정측면·전신·단순 배경)로 맞췄다.

⚠️ **W11 그대로**: 조건 이미지 좌표로 마스크를 판단하지 않는다. 비율이 다르다.
   마스크는 클라가 준 복셀이 유일한 진실이다.

## ★ 조건은 **3090 이 만든다** — 사용자에게 이미지를 요구하지 않는다

Unity→3090 구간은 자연어 그대로다. 형태 편집이 들어오면 3090 이 t2i 로 조건 이미지를
만들어 multipart 로 동봉한다 (`meta` + `image` — generate 와 같은 관례).

🔴 **조건을 못 만들면 조건 없이 몰래 진행하지 않는다.** D40 상 그건 원본 머리로
회귀하는 길이고, 결과만 보면 "편집이 약하다" 로 오독된다. 끄려면 `EDIT_CONDITION_IMAGE=0`.

⚠️ `CONDITION_TEMPLATE` 은 **자산 종류를 가정한다**(측면·전신). 지금은 moto-b 하나라
   그대로 두지만, 자산군이 늘면 여기가 조용히 틀린다.

## ★ 형태 편집 end-to-end — 성립했다

```
POST /v2/assets/v3-moto-b/edits  "라이더 머리를 아이언맨 머리로 바꿔줘"
  [ 0.0s] mask       마스크 검증
  [ 3.0s] op         자연어 → op (replace_region)
  [ 6.0s] condition  조건 이미지 생성 (바뀐 뒤 전신)
  [33.0s] repaint    <EDIT_HOST> VoxHammer
  [39.1s] succeeded  청크 74 · 제거 0 · 판본 {4: 74}
→ patch v1→v2 · changed 74 / removed 0 · contract v4 chunk_size 4
```

⚠️ **마스크는 뒷바퀴(1,386셀)를 썼다.** 머리 마스크(476셀)가 아직 3090 에 없다 —
   경로가 도는 것은 증명됐지만 **"아이언맨 머리로 바뀌었나" 는 아직 판정 안 됐다.**
   머리 마스크가 오면 그대로 다시 돌리면 된다.

## 상류가 필요로 한 파일 둘 — 내 store 에 있었다

사유 전파를 켠 덕에 상류의 진짜 오류가 보였고, 둘 다 3090 원본으로 채웠다:

| 파일 | 크기 | sha256 | 대조 |
|---|---|---|---|
| `slat.safetensors` | 439,848 B | `b8b1f91c546b3ced…` | 좌표 9,150 = manifest `voxel_count_total` (D28) |
| `input.png` (생성에 쓴 RGBA) | 994,830 B | `ef7541b2093c00f7…` | — |

둘 다 **없던 자리에 추가**했고(덮어쓰기 아님), 받는 쪽에서 sha256 을 읽어 확인했다 (D27).
**재생성하지 않았다** — 재생성하면 바이트가 갈린다.

## 🔴 §7 위반 하나 — 내가 만들고 내가 잡았다

`httpx.raise_for_status()` 의 예외 메시지에 **URL 이 통째로** 들어간다. 그게 잡 상태로
올라가 앱 화면에 **공인 IP 가 찍혔다.** 실측으로 겪었다.

이제 `raise_for_status()` 를 안 쓰고 상태·본문만 `parse_upstream_error` 로 넘긴다.
테스트가 IP·URL 부재를 잠근다 (`test_no_host_or_port_leaks_into_the_message`).
사유는 전파하되 **주소는 전파하지 않는다.**
