# W18 — D45 델타 실험 실측 (3090)

`runG.glb` 를 **우리 델타 파이프라인**에 통과시킨 결과다. GPU 를 쓰지 않았다.
이 숫자가 D56(레벨2 종결)이 추정이 아니라 실측 위에 서게 하는 값이다.

## ★ 결론 — "VoxHammer 절감률 ≈0%" 는 우리 파이프라인의 값이 아니다 (D61-a)

| | 절감률 |
|---|---|
| 승계·부기 없이 재인코딩 (= 그 말의 출처) | **0%** (승계 동일률 0.0%) |
| overflow 필터 없이 부기만 (문턱 1) | **5.0%** |
| **부기 + 승계 + D54 필터 (문턱 56)** | **43.2%** (청크 수로는 47.8%) |

`reencoded_identity = 0.0%` 를 같은 실행에서 확인했다 — 재디코딩하면 부기 밖
청크도 **한 개도** 부모와 바이트가 같지 않다. 그래서 해시로 부기를 유도하면
전부가 "바뀐 청크" 가 되고 절감이 0 이 된다. 우리는 **점유 비교**로 정한다.

## 수치

| 항목 | 값 |
|---|---|
| 부기 청크 | **230** (마스크·halo1 226 ∪ overflow 8) |
| 실제 전송 청크 | **72** (부기 중 결과 메시에 존재하는 것) |
| 전송 바이트 | **156,972 B** |
| 전체 재전송 바이트 (같은 메시·같은 인코더) | **276,204 B** |
| **절감률** | **43.2%** |
| 승계 청크 | 68 · 6,393,476 B |
| **승계 바이트 동일률** | **100.0%** — 항진명제다 (D5-b). 100% 가 아니면 승계 경로가 깨진 것 |
| 최종 자산 | 140청크 · 6,550,448 B |

## 문턱 근거 — 데이터에서 골랐다

마스크(+halo1) 밖 **신규** 복셀 702개, 26-연결 성분 123개. 크기 분포:

```
131, 130, 24, 19, 18, 15, 14, 13, 12, 12, ...
      └──────┘
   가장 큰 배수 간극 24 → 130 (5.4배)
```

규칙: **관측된 성분 크기의 가장 큰 배수 간극에서 기하중점을 잡는다.**
→ √(24 × 130) ≈ **56**. 숫자를 먼저 정하고 데이터를 맞추지 않았다.

문턱 25–131 은 전부 같은 결과를 낸다(고원). 선택값 56 은 그 고원의 한복판이다.

## 측면 머리는 살아남았는가 — **살아남았다. 손실 0%**

조립한 최종 자산을 다시 복셀화해 절단면 z44 위 성분을 셌다:

| 문턱 | 중앙 | 좌 | 우 | 델타 전 대비 |
|---|---|---|---|---|
| 1 (필터 없음) | 539 | 363 | 358 | 0% |
| **56 (선택)** | **539** | **363** | **358** | **0%** |
| 132 (과필터) | 539 | 300 | 296 | 측면 머리 **−17%** |

문턱 132 부터 측면 머리의 바깥 끝(131·130셀)이 잘려 나간다. 선택값 56 은 안전하다.

## ⚠️ 이 숫자를 읽을 때

1. **`runG.glb` 는 면이 원본의 3.1%** 다 (13,398 vs 426,600). 저해상도 export 라
   절대 바이트는 A5000 풀해상도 디코드와 다르다. 절감률은 분자·분모를 같은
   메시로 통일해 잰 값이라 비율은 유효하지만, **바이트 절대값은 인용하지 마라.**
   처음에 델타(저해상도)와 승계(고해상도)를 섞어 재서 **97.6%** 가 나왔다 —
   그건 델타가 잘해서가 아니라 분모가 무거워서였다.
2. **격자가 slat 이 아니라 표면 복셀화다.** `.glb` 에서 시작하므로 D28 정본 격자가
   아니다. base 도 같은 방식으로 복셀화해 비교 가능성은 맞췄다(base 10,264 /
   runG 8,817). A5000 의 slat 기준 overflow(602/80청크·halo2)와는 다른 수라
   **직접 비교하지 마라.**
3. **43.2% 는 마스크 크기가 지배한다.** W14 마스크는 격자의 28.4%(74,340셀)라
   자산 청크의 절반 이상이 부기에 든다. 마스크가 작아지면 절감은 올라간다.
4. `w14_mask.npy` 는 셀 수(74,340)와 bbox 가 스펙과 정확히 일치하지만
   **지문이 스펙의 값과 다르다** — 직렬화 규약이 갈린 것으로 보인다. 미해결.
